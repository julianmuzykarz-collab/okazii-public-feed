# Pigu / PHH public feed

Public endpoint for the PHH Marketplace XML product feed.

Primary feed URL:
- https://raw.githubusercontent.com/julianmuzykarz-collab/okazii-public-feed/main/pigu/feed.xml

Compatibility alias:
- https://raw.githubusercontent.com/julianmuzykarz-collab/okazii-public-feed/main/pigu/products.xml

Source system: Sellasist.
Target languages: Lithuanian (LT), Latvian (LV), Estonian (EE).

Current logistics policy:
- dimensions: 50 x 30 x 15 cm for every Pigu product;
- positive Sellasist weight is preserved;
- missing/zero weight falls back to 1 kg in the generator.

Both XML files are intended to contain the same feed content. Do not add credentials or API secrets to this public repository.
